## ✏️ How to Customize

### Update Your Content
1. Open `index.html`
2. Update text to reflect your current status
3. Add new certificates as you earn them
4. Update skills as you learn more

### Change Colors
In `styles.css`, find the `:root` section at the top:
```css
:root {
    --primary: #14b8a6;  /* Main aqua green color */
    --primary-dark: #0d9488;  /* Darker shade */
    /* Change these to your preferred colors */
}
```

### Add New Work
When you complete new projects:
1. Add the project image to the `images/` folder
2. Copy one of the existing work items in `index.html`
3. Update the text and image path

## 🚀 How to Use
