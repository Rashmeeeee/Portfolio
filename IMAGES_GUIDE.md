# 🖼️ What Images to Add to Your Portfolio

## For Your Work Section

Since you designed **complete game interfaces and graphics** at Danson Solution, here's what you should showcase:

### Screenshots to Take:

1. **Game Interface Screenshots**
   - Full game screens you designed
   - Menu screens
   - Game play UI
   - Character selection screens
   - Settings panels

2. **Graphic Assets**
   - Buttons you created
   - Icons and UI elements
   - Background graphics
   - Character illustrations (if you made them)

3. **Before/After or Process**
   - Wireframes → Final design
   - Sketches → Digital version

### How to Prepare Images:

1. **Take Screenshots** from Figma or your design files
2. **Save as JPG or PNG**
3. **Recommended size**: 1200x800px (landscape)
4. **Name it**: `game-ui.jpg` or `game-ui-1.jpg`, `game-ui-2.jpg`, etc.

### Where to Put Them:

Save your images in the `images/` folder:
```
images/
├── profile1.jpg ✓ (you have this)
├── profile2.jpg ✓ (you have this)
├── game-ui.jpg ← Add your game UI screenshot here
├── game-ui-2.jpg ← (optional) More screenshots
└── game-ui-3.jpg ← (optional) More screenshots
```

### Alternative: Use Placeholder for Now

If you don't have screenshots ready:
- The portfolio shows a placeholder box
- It says "Add screenshots of your game UI designs here"
- You can add real images later

## For Personal Practice Section

You mentioned practicing graphic design. Here's what you can add:

### Personal Work to Show:

1. **Posters you designed**
2. **Social media graphics**

4. **UI concepts from Figma**

```html

    <img src="images/poster-design.jpg" alt="Poster Design">
    <img src="images/logo-design.jpg" alt="Logo Design">

```

## Tips:

✅ **DO:**
- Use high-quality screenshots
- Show your best work
- Include work from your internship
- Add captions explaining what you did

❌ **DON'T:**
- Use random stock images
- Show work that isn't yours
- Use blurry or low-quality images

## Need Help Getting Screenshots?

1. Open your Figma files
2. Select the frame you want
3. Right-click → "Copy as PNG" or "Export"
4. Paste or save the image
5. Rename it to `game-ui.jpg`
6. Put it in the `images/` folder
